# تاكسي الإسكندرية 3D — نسخة ويندوز

## التثبيت
نزّل ملف `Taxi-Alexandria-Setup-1.0.0-x64.exe` من صفحة إصدارات GitHub، ثم افتحه واتبع خطوات التثبيت. المُثبّت ينشئ اختصارًا على سطح المكتب وقائمة Start.

## البناء محليًا
يتطلب Node.js 24:
```bash
npm install
npm run build:desktop
```
ملف التثبيت الناتج موجود في مجلد `release/`.

## استكشاف أخطاء الشاشة السوداء
1. حدّث تعريف كارت الشاشة من الشركة المصنّعة.
2. أغلق برامج الـ overlay التي تتدخل في الرسوم مثل بعض أدوات تسجيل الألعاب، ثم أعد تشغيل اللعبة.
3. إذا ظهر مربع خطأ، احتفظ برسالته الكاملة عند الإبلاغ عن المشكلة.

## حدود النسخة الحالية
المدينة الحالية مبنية من مجسمات إجرائية وإحداثيات تقريبية وليست نسخة جغرافية مطابقة لكل شوارع ومبانٍ الإسكندرية. المطابقة الجغرافية الدقيقة تحتاج إدخال بيانات خرائط وواجهات وموديلات ثلاثية الأبعاد حقيقية مع نسب المصادر وتراخيصها.
